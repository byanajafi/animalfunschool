# ?? Belajar Hewan � Aplikasi Edukasi untuk Anak-Anak

Versi ini adalah aplikasi edukasi anak yang fokus pada pembelajaran hewan, suara, fakta, dan modul Calistung plus kuis.

## ?? Fitur Utama

- Halaman Home dengan navigasi sederhana
- Belajar Hewan: daftar hewan, suara, dan fakta menarik
- Calistung: modul membaca, menulis, dan berhitung
- Kuis & Game: permainan edukatif untuk anak

## ?? Struktur Folder

```
index.html
belajar-hewan.html
calistung.html
kuis.html
css/
js/
assets/
```

## ?? Menjalankan Aplikasi

1. Buka `index.html` langsung, atau jalankan server lokal:

```bash
python -m http.server 8000
```

2. Buka `http://localhost:8000`

## ?? Catatan

- Fokus aplikasi hanya pada pengalaman belajar hewan dan latihan Calistung.
- Semua fitur eksternal non-esensial telah dibersihkan dari versi ini.
- Gunakan browser modern untuk hasil terbaik.

## ?? Troubleshooting

- Aplikasi tidak muncul: gunakan web server lokal
- Audio tidak terdengar: pastikan file audio ada di `assets/sounds/`
- Tampilan rusak: refresh cache, coba browser lain
