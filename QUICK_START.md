# 🚀 Quick Start - Belajar Hewan

Panduan singkat untuk menjalankan versi tanpa fitur lama.

1. Clone atau download repo, lalu buka folder project.
2. Jalankan server lokal (opsional):

```bash
python -m http.server 8000
```

3. Buka browser: `http://localhost:8000`

Struktur inti:

```
index.html
belajar-hewan.html
calistung.html
kuis.html
css/
js/
assets/
```

Fitur utama: Home, Belajar Hewan, Calistung, Kuis & Game. Semua instruksi lama yang tidak digunakan telah dihapus dari versi ini.

Jika ingin menambahkan konten atau audio, letakkan file di `assets/sounds/` dan perbarui `js/config.js`.

### Learning Path
```
Home → Belajar Hewan → Calistung (Vocab/Reading/Writing/Counting) → Games
```

### Tips
- 💡 Jangan buru-buru, biarkan anak eksplor
- 💡 Game/kuis untuk assessment
- 💡 Monitor progress via console (F12)
